## Contoh: Hermes cron untuk reply draft (BUKAN auto-send)

```bash
# Hermes kerangka draft reply untuk review manusia
hermes cron add "*/30 * * * *" "Cek inbox WAHA session all-in-one-device untuk pesan masuk 30 menit terakhir (GET /api/messages per chat). Untuk tiap pesan yang belum di-reply, draft balasan yang sopan dan relevan. Kirim DRAFT ke Telegram untuk saya review. JANGAN auto-send ke WAHA." --name "Draft WA replies" --deliver telegram
```

## Contoh: weekly broadcast draft cron

```bash
hermes cron add "0 10 * * 1" "Draft broadcast WA mingguan. Pilih 1 dari 5 template di ~/waha/templates.txt secara random. Personalisasi {name} dari ~/waha/customers.csv. Tampilkan 3 preview untuk saya review sebelum kirim manual via scripts/lib/broadcast.py. JANGAN auto-send." --name "Draft broadcast WA" --deliver telegram
```

## Contoh: opt-out handler (script sederhana)

Simpan ini di `~/.waha-marketing/scripts/handle-optout.sh`:

```bash
#!/usr/bin/env bash
# Tambah nomor ke opt-out list. Panggil manual saat ada yang balas STOP.
PHONE="$1"
OPT_OUT="${WAHA_CONFIG_DIR:-$HOME/.waha-marketing}/opt_out.csv"
[[ -f "$OPT_OUT" ]] || echo "phone,reason,date" > "$OPT_OUT"
echo "$PHONE,user_opt_out_reply,$(date -I)" >> "$OPT_OUT"
echo "Added $PHONE to opt_out. Akan di-skip di broadcast berikutnya."
# Hapus dari customers.csv aktif juga (manual review recommended)
```
