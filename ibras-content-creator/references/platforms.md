# Platforms — Format, Length, CTA, Cadence (2026 data)

> Data dari HubSpot State of Marketing 2026 + Digital Applied + SocialPilot +
> Opus.pro + platform official guidance. Update ~6 bulan.

## Instagram (Indonesia: top 3 channel untuk UMKM)

| Aspek | Rekomendasi 2026 |
|---|---|
| **Format dominan** | Reels (reach terbesar), Carousel (save tertinggi), Story (engagement) |
| **Feed post length** | Caption 100-2200 karakter. Hook di 220 karakter pertama (sebelum "more") |
| **Reels length** | 7-15 detik (max reach), 30-60 (storytelling). Hook 3 detik pertama |
| **Carousel slides** | 7-10 slide optimal (1 hook, 5-8 isi, 1 CTA) |
| **Hashtag** | 3-5 relevan. Jangan 30 spam. Niche > broad |
| **Engagement rate avg** | 0.7% (feed), 1.5%+ (reels bagus) |
| **Best time WIB** | 11am-1pm, 7pm-9pm |
| **Cadence sustainable** | 3-4 feed/reels seminggu + daily story |
| **CTA** | Question ("komentar di bawah"), Save ("save buat nanti"), Share ("kirim ke teman") |
| **Penalty** | Bot automation (shadowban), buy followers, identical crosspost |

## TikTok (Indonesia: top channel untuk reach organik)

| Aspek | Rekomendasi 2026 |
|---|---|
| **Algorithm 2026** | Watch time + completion rate + rewatch > follower count. Favors human creators over AI |
| **Length** | 7-15 detik (viral), 30-60 (depth). Hook 1.5-3 detik |
| **Captions** | 50-80 kata, mendukung video (bukan inti) |
| **Hashtag** | 3-5 niche. #fyp mati (algoritma abaikan). Use trending audio |
| **Best time WIB** | 6am-10am, 7pm-11pm |
| **Cadence** | 1-2/hari (kalau sanggup), minimum 5/seminggu |
| **CTA** | Soft ("follow for part 2"), question di caption/comment pin |
| **Penalty** | Low-signal volume posting, AI content murni tanpa human touch |

## YouTube (evergreen, search-driven)

| Aspek | Rekomendasi 2026 |
|---|---|
| **Algorithm 2026** | Search + recommendation. Click-through rate (CTR) + watch time penting |
| **Length** | 8-12 menit sweet spot (monetisasi). Long-form 20+ untuk depth |
| **Title** | <60 char. Searchable + curiosity. Setengah dari battle |
| **Thumbnail** | High contrast, face + text 3-5 kata. A/B test |
| **Description** | 100-300 kata SEO + timestamps + CTA subscribe |
| **Tags** | 5-10 relevan |
| **Best time WIB** | Upload 2pm-4pm (audience activity peak evening) |
| **Cadence** | 1-2/minggu konsisten > sporadis |
| **CTA** | Subscribe + bell, "watch this next" end screen |
| **Penalty** | AI-slop channels demonetized massal 2026 |

## X / Twitter (build in public, indie hacker)

| Aspek | Rekomendasi 2026 |
|---|---|
| **Algorithm 2026** | AI-driven ranking. Predicted engagement (like/reply/retweet) |
| **Single tweet** | Max 280 char. Hook + value + CTA |
| **Thread** | 7-10 tweet. Hook tweet + isi + CTA tweet |
| **Best format** | Threads, hot takes (defensible), build-in-public |
| **Cadence** | 3-5/hari ATAU 1 thread + 3-5 reply/hari |
| **CTA** | RT/like/reply. Question perform |
| **Penalty** | Bot behavior, rapid posting, identical crosspost |

## LinkedIn (B2B, freelance clients, founder-led)

| Aspek | Rekomendasi 2026 |
|---|---|
| **Algorithm 2026** | "Depth Score" — dwell time 61+ detik, multi-reply comment threads weighted tinggi |
| **Feed allocation** | Personal profile ~65%, company page ~5%. Founder-led > logo |
| **Length** | 200-300 kata. Single takeaway. Ends dengan question |
| **Format** | Carousel 6.6% engagement, single image 4.85%, text 4.0% |
| **External link** | -60% reach. Taruh link di komentar pertama |
| **Best time WIB** | 8am-10am weekday |
| **Cadence** | 2-3/minggu konsisten |
| **CTA** | Question, "DM saya kalau...", save |
| **Penalty** | Engagement pods (severe shadowban), AI-written generik, "great post!" comments |

## Blog / SEO (evergreen, owned)

| Aspek | Rekomendasi 2026 |
|---|---|
| **Length** | 1500-2500 kata untuk competitive keyword. 800+ cukup untuk niche |
| **Structure** | H1 + H2/H3 + FAQ + internal links. SEO title <60 char |
| **Meta description** | 150-160 char |
| **Cadence** | 1-2/bulan konsisten > burst |
| **CTA** | Lead magnet (email capture), related post, comment |

## Pemilihan channel (aturan 1-channel-deep)

Jangan ada di 5 platform shallow. Pilih 1-2 channel utama, perdalam.

| Niche | Channel utama | Alasan |
|---|---|---|
| Fisik/lifestyle/F&B | Instagram + TikTok | Visual, discovery |
| Edukasi/tutorial | YouTube + TikTok | Long-form + short clip |
| Indie hacker/SaaS | X + LinkedIn | Build in public + B2B |
| B2B/profesional | LinkedIn | Decision makers |
| Illustration/design | Instagram + Behance/Cara | Portfolio + audience |
| Local service | Instagram + Google Business | Visual + local SEO |

## Anti-pattern lintas platform

- ❌ **Identical crosspost** — algoritma penalti + audience fatigue
- ❌ **Same hook di semua platform** — TiTikTok hook ≠ LinkedIn hook
- ❌ **Posting 10x sehari di semua platform** — burnout + signal rendah
- ❌ **Auto-DM follow-up** — banned vector
- ❌ **Buy followers/engagement** — death spiral
