## Aturan kalender

1. **Pilih slot realistis.** Kalau kamu tidak bisa 3x TikTok sehari, jangan paksa.
2. **Sisihkan 1-2 slot kosong** untuk spontan/tren.
3. **Hormati rasio 5:1 minimum** (5 value : 1 promote).
4. **Pillar distribusi merata.**
5. **Best time WIB per platform** (lihat platforms.md).
6. **Rest day wajib** (min 1 hari bukan berarti 0 post, tapi tidak ada "must post" pressure).

## Review mingguan (ahad malam)

- [ ] Konten minggu depan sudah draft semua?
- [ ] Pillar distribusi merata?
- [ ] Rasio value:promote OK?
- [ ] Slot spontaneous diisi sama tren/feedback audience?
- [ ] Apa yang underperform minggu ini? Pelajaran untuk minggu depan?
